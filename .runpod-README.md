The `.runpod/` directory was removed in this fork.

`hub.json` and `tests.json` exist to publish a worker to the RunPod Hub. This fork is
deployed straight from GitHub onto a private endpoint, where the Hub never sees it — but
their presence still made every deploy run a build-time test that had to rent its own GPU,
and that rental kept failing:

    There were no instances available for your specified GPU ...
    All returned supply constraints.

Six cards across three attempts, while the endpoint itself had capacity the whole time.
The build's GPU pool is evidently not the endpoint's.

Restore them from upstream if this is ever published to the Hub:
https://github.com/ashleykleynhans/runpod-worker-real-esrgan/tree/main/.runpod
